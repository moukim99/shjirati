# شجيراتي

تطبيق Android محلي وبسيط لمساعدة كبار السن على تذكر مواعيد سقي الأشجار والشتلات والخضروات.

## الرؤية
- واجهة عربية RTL شديدة البساطة.
- لا حسابات ولا خادم ولا مزامنة سحابية.
- البيانات والصور تبقى على الهاتف.
- تذكيرات سقي محلية.
- جدول سقي حسب عدد الأيام أو أيام الأسبوع.
- سجل لعمليات السقي.
- جداول موسمية تتغير تلقائياً حسب الموسم.
- ثيم موسمي للواجهة.

## التقنية
- Kotlin
- Jetpack Compose
- Room / SQLite
- MVVM + Clean Architecture
- Coroutines + Flow
- Android Local Notifications

## الهيكل الحالي
- `data/local`: قاعدة Room وكيانات النباتات والسقي.
- `data`: تنفيذ Repository.
- `domain`: منطق الموسم وعقود المجال.
- `ui`: Compose وViewModels والثيم.

## الحالة
النسخة الحالية هي الأساس التقني الأول للمشروع. الخطوة التالية هي بناء تدفق الاستخدام الأساسي: إضافة نبتة، تحديد جدول السقي، عرض مهام اليوم، تسجيل السقي، ثم نظام الإشعارات المحلية.
